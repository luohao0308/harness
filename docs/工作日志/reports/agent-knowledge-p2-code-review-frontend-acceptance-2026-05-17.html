新增功能总览

Source 生命周期

验收含义：ACTIVE 才能被当前检索命中；DISABLED/ARCHIVED 不应参与当前检索。

Document 版本与失败路径

验收含义：失败版本会显示错误；相同 idempotency 重试仍失败，不能出现“无 chunk 成功版本”。

修复清单

修复 1：FAILED document 不再被成功幂等复用

previous document 查询增加 status == INDEXED 限制，并补上 latest version 查询的 limit(1)。失败后重试会继续走失败路径，不会写 document_versioned 成功审计。

代码：services/api-server/app/knowledge.py；测试：test_failed_reingest_idempotency_retry_remains_failed。

修复 2：multipart 鉴权与大小边界前置

source import 先 role + agent 校验；document import / version import 先 source/document 权限校验；body 通过 request.stream() 累积读取，超过上限立即 413。

测试：unauthorized actor invalid body 返回 403；oversized multipart 返回 413。

修复 3：真实浏览器 .md MIME 容错

后端不再依赖浏览器 part MIME 必须准确；只允许 .txt/.md 扩展名，并要求内容可 UTF-8 解码，再规范化为 text/plain 或 text/markdown。

修复 4：org scope 前端走显式 admin 边界

org source 创建、scope change、org source 生命周期操作使用 admin token；若没有 admin token，org scope 控件会被禁用。

前端验收路径

打开 Agent Studio
进入 /agents，选择 agent，确认 Knowledge 面板加载 source 列表。
创建文本知识源
创建 agent-scoped source，确认显示 ACTIVE、HEALTHY、agent。
上传 .txt / .md
上传小文件应成功；上传 .pdf 或超大文件应被拒绝，错误信息可读。
新增文档与 reingest
新增 sibling document；重新导入原 document 后，新版本 INDEXED，旧版本 SUPERSEDED。
生命周期操作
disable 后不可检索；enable 后恢复；archive 需确认，归档后不可检索。
org scope
scope change 会确认，并通过 admin token 调用；同 org agent 可见，foreign org 不可见。

验收勾选表

  • Source list 显示 status、health、scope、latest documents。
  • Source detail 显示 document/version history。
  • .txt 文件上传成功。
  • .md 文件在浏览器 MIME 不稳定时仍可上传。
  • .pdf 文件被拒绝。
  • 超大 multipart 文件被 413 拒绝。
  • Reingest 成功后旧版本 SUPERSEDED，旧 chunks STALE。
  • Reingest 失败后旧 INDEXED 版本仍可用。
  • 同 idempotency 失败重试仍失败，不产生成功 audit。
  • Disable 后 retrieval 不命中该 source。
  • Enable 后 retrieval 恢复。
  • Archive 后不参与 retrieval。
  • Scope change 有确认弹窗。
  • org scope 调用使用 admin token。
  • 同 org 其他 agent 能看到 org source。
  • foreign org 看不到/操作不到 source。
