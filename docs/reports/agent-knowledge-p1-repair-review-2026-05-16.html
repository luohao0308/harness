前端验收路径

  1. 在 Agent Studio / RAG 知识源区域添加一份包含明确事实的知识源，例如 orion anchor local fact。
  2. 进入 Workspace，问一个能命中知识源的问题，等待 Run 完成。
  3. 打开该 Run 的 Run Detail，定位 知识依据 区域。
  4. 确认出现 Prompt 组装审计：能看到 manifest ...、included N、omitted N 和 sha256 ...。
  5. 确认出现 策略 / 省略审计：能看到 allowed，如存在未选候选，还应看到 omitted。
  6. 确认下方仍展示 检索命中 和 引用，citation 的 hit id 能对应检索命中。
  7. 再问一个无知识源支撑的问题，确认状态为 insufficient，且 UI/API 不应显示伪造 citation。
  8. 验收 blocked 项：当前缺 Docker/private deployment 证明，所以不要在进度文档中标记 verified baseline。
