# Portfolio Demo Spec

## Demo Scenario

```text
GitHub Issue
-> Agent Chat input
-> Planner creates DAG
-> Subagents analyze in parallel
-> Executor calls tools
-> Guardrail blocks dangerous action
-> Event Sourcing records all transitions
-> Replay reconstructs the run
-> Eval Harness saves and grades the run
-> Dashboard shows trace, replay, cost, latency, and quality metrics
```
