# 校准报告

校准报告比较专家选择置信度和实际结果。Harness 会保存选择决策、候选 slug、备选项、选择器来源、置信度以及后续成功证据。报告把决策分入不同置信度桶，并在样本足够时计算 Expected Calibration Error。

低样本报告仍然有价值，因为它证明系统正在收集证据；但样本不足时不应单独驱动重大路由策略。评审时应同时查看失败任务、专家输出、工具权限、触发关键词和 Eval 契约结果。

校准适合在专家模板和扇出规则稳定后使用。高置信度但低成功率通常说明提示词漂移、触发关键词太弱、缺少工具，或输出契约与真实任务不匹配。修复后重新跑同一数据集，确认置信度和通过率一起改善。
