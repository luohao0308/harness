# Eval 数据集

Eval 数据集收集可以证明智能体能力在改动后仍然有效的用例。用例可以手工创建，也可以从完成的运行保存。保存用例会保留任务输入、期望状态、能力快照、证据选择器和契约元数据。

Eval 运行会评分每个用例，并生成聚合指标、回归差异、通过率、失败原因、成本证据和 Trace 详情。企业交付时，Eval 不是“额外报告”，而是证明提示词、工具权限、知识源、子智能体和模型成本没有漂移的门禁。

数据集要足够小，便于频繁回归；也要足够聚焦，便于解释失败。建议把证据绑定、工具行为、专家路由、安全、角色人格和成本分别放入不同数据集。基线必须来自已知良好且证据可检查的运行，而不是未经验证的样例输出。
