# MCP 服务器

MCP 允许 Harness 通过协议边界发现和执行外部工具。HTTP 与 SSE 服务器使用已配置端点；stdio 服务器只能通过注入的沙箱执行器运行，因此 API 服务不会直接启动任意主机进程。发现过程会为子工具登记 schema、风险元数据和服务器身份。

即使工具来自 MCP，执行路径仍然经过能力注册表、工具运行器、策略检查、审批、工具调用审计和事件存储。这样可以把协议接入和企业权限控制分开，避免外部服务器绕过 Harness 的审计边界。

当供应商已经提供可用协议服务器，或团队需要隔离工具所有权时，可以使用 MCP。未审查的 MCP 服务器应视为不可信代码。暴露给智能体前，必须验证 schema、命令路径、环境变量、超时设置、网络边界和密钥引用。
