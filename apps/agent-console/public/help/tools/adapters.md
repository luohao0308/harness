# 真实适配器

适配器把 Harness 工具连接到外部系统。当前适配器族包括 GitHub、Slack、Notion、Linear、代码解释器、沙箱文件操作、本地 MCP 发现，以及内置 shell 或文件系统操作。每个适配器都会把结构化工具输入转换为供应商调用，隐藏密钥，并用稳定格式返回错误。

工具调用证据会记录适配器来源、schema 哈希、能力快照、请求状态和输出摘要。具备写入能力的适配器必须具备幂等键和高风险元数据，避免重试时重复发消息、重复建单或重复修改仓库。

生产接入前，在服务端配置运行时密钥，并从工具配置页测试健康状态。权限要保持最小化：Slack 发帖工具不需要 GitHub 仓库权限，代码解释器默认也不需要网络访问。任何新增写入面都应该配套 Eval 或冒烟用例。
