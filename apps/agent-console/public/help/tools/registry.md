# 工具注册表

工具注册表列出智能体可以请求、平台可以执行的动作。每个工具都有输入 schema、风险等级、来源、允许角色、沙箱要求和审批行为。低风险只读操作通常可以直接运行；写入、网络、shell 执行和外部适配器应保持策略门禁。

全局注册表展示可用能力，但运行时执行依赖智能体的能力附件快照，而不是松散名称查找。工具调用证据会复制工具元数据，让后续审计知道当时使用的是哪个版本、哪个风险标签、哪组配置哈希。

使用智能体过滤器检查某个智能体实际挂载的工具集合。生产启用前要检查输入 schema、密钥引用、幂等行为、网络边界、沙箱设置和审计输出。高风险工具应配套审批、Eval 用例和发布冒烟覆盖。
