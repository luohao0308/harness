# 排障指南

当私有 Harness 部署或控制台工作流不符合预期时，先使用本指南。每个案例都说明症状、最快检查、修复方向和日志位置。排障顺序建议从最靠近故障的服务开始，再向外检查代理、浏览器和外部供应商。

### 1. Docker 后台服务不可用
症状：Compose 命令在任何 Harness 服务启动前失败。先运行 `docker info`，确认当前用户可以访问 Docker socket。修复本地 Docker Engine 服务或用户组权限后，重新执行 `docker compose config`。日志在 Docker Desktop 或系统服务日志中。

### 2. Compose 环境变量不完整
症状：`compose.production.yml` 报告必需变量缺失。检查 `POSTGRES_PASSWORD`、`REDIS_PASSWORD` 和 `HARNESS_DOMAIN`。修复命令使用的 `.env` 文件后重新运行 compose config。校验失败前不会有 Harness 服务日志。

### 3. Postgres 不健康
症状：readiness 一直为 false，API 启动等待数据库。检查 `docker compose ps postgres`，并在容器内运行 `pg_isready`。修复凭据、卷权限或端口冲突。日志在 `docker compose logs postgres`。

### 4. Redis 鉴权失败
症状：readiness 报告 Redis 不可用，或缓存操作回退到内存。检查 `REDIS_PASSWORD` 是否与 API 的 `REDIS_URL` 一致。修复密钥后重启 Redis 和 API。日志在 `docker compose logs redis api-server`。

### 5. Alembic 迁移失败
症状：`db-migrate` 非零退出，API 无法健康启动。查看 `docker compose logs db-migrate` 中失败的 revision。修复迁移或数据库状态后，在本地先运行迁移预检。日志在迁移任务容器中。

### 6. API 就绪检查为 false
症状：`/api/health/readiness` 返回 `ready: false`。检查 JSON 依赖列表中的数据库、Redis 和模型供应商状态。先修复失败依赖，再重启 API。日志在 `docker compose logs api-server`。

### 7. Caddy 无法签发 TLS
症状：HTTPS 没有起来，Caddy 日志出现 ACME 错误。检查 DNS、公网 80/443 端口可达性和 `HARNESS_EMAIL`。修复域名路由，或在私有验证时使用本地 HTTP 配置。日志在 `docker compose logs caddy`。

### 8. 代理后的 API 路由返回 404
症状：直连 API 正常，但通过公网域名访问 `/api/...` 返回 404。检查 Caddy 或 Nginx 规则是否保留 `/api` 前缀。修复代理规则并重载代理。日志在代理访问日志和 API 请求日志中。

### 9. 控制台空白页
症状：浏览器只显示空壳或白屏。检查 DevTools console、`index-*.js` 加载状态和前端错误报告。修复静态资源路由、陈旧缓存或 TypeScript 运行时错误。日志在浏览器控制台和 `/settings/frontend-errors`。

### 10. 控制台指向错误 API
症状：控制台界面能加载，但所有 API 调用失败。检查构建镜像中的 `VITE_API_BASE_URL` 和浏览器网络请求主机。修改公开 URL 后需要重建控制台。日志在浏览器网络面板和 API 访问日志中。

### 11. 登录返回 401
症状：邮箱密码或 bearer token 被拒绝。检查 token 类型、过期时间和组织成员状态。修复凭据、刷新 token 或接受成员邀请。日志在 API 鉴权日志和组织审计事件中。

### 12. API Key 被拒绝
症状：自动化客户端收到 `Bearer token invalid` 或 `API key revoked`。检查 key 前缀、scope、过期时间和用户成员关系。从设置页轮换 key，更新客户端密钥后重试。日志在 API 鉴权日志和审计事件中。

### 13. OAuth 回调失败
症状：供应商跳转回来后，回调页显示鉴权错误。检查供应商 client id、回调 URL 和 state 参数。修复供应商配置，并重新部署控制台/API 环境变量。日志在 API 鉴权日志和浏览器网络面板中。

### 14. RBAC 拒绝预期动作
症状：admin 或 engineer 执行动作返回 403。检查当前主体角色、权限列表和组织 id。修复成员角色或 API Key 范围。日志在组织审计事件和 API 鉴权 Trace 中。

### 15. 模型供应商密钥无效
症状：智能体运行在工具执行前的规划阶段失败。检查就绪状态中的供应商状态和模型设置页。修复供应商标识、Base URL 或所选模型名称。日志在模型网关日志和运行详情的模型调用记录中。

### 16. 模型请求超时
症状：运行在规划或执行等待过久后进入失败状态。检查供应商延迟、模型超时设置和重试计数。修复模型路由，或降低任务输入规模。日志在模型调用 span 和 API 日志中。

### 17. 知识连接器没有结果
症状：Dify、Coze 或自定义连接器同步成功，但检索为空。检查连接器端点、密钥引用和已索引文档数量。重新索引知识源，并用样例查询验证。日志在知识源详情和 API 连接器日志中。

### 18. 知识源一直处于 indexing
症状：知识源停留在 `INDEXING`，无法进入可用状态。检查导入工作进程日志、文档大小和解析错误。修复源内容或重新运行导入。日志在 API 日志和知识源元数据面板中。

### 19. RAG 回答没有引用
症状：工作区有回答文本，但证据绑定为空。检查智能体是否绑定了已索引知识源，并确认 grounding 已启用。绑定知识源后重新运行检索，并检查清单。日志在运行详情的证据绑定和上下文清单面板中。

### 20. 智能体运行卡在规划阶段
症状：运行保持 `PLANNING`，没有生成步骤。检查模型网关健康、计划修复日志和输入大小。修复模型访问，或缩短请求。日志在运行详情事件和模型调用记录中。

### 21. 智能体运行一直处于运行中
症状：运行长时间不能完成或失败。检查活动任务步骤、沙箱命令和工作进程可用性。修复阻塞工作进程后取消或恢复运行。日志在运行事件、工作进程日志和沙箱命令记录中。

### 22. 工具调用被 DENIED
症状：工作区显示工具被拒绝或需要审批。检查工具策略、风险等级、角色和审批状态。调整策略，或从审批页面批准该调用。日志在工具调用详情和审计事件中。

### 23. 沙箱无法启动
症状：工具执行在出现命令输出前失败。检查 Docker socket 挂载、沙箱镜像可用性和 WarmPool 健康状态。修复 Docker 访问，或预拉取镜像。日志在 API 沙箱日志和 Docker 后台服务日志中。

### 24. WarmPool 为空
症状：工具调用发生冷启动，或资源池指标显示零个可用沙箱。检查 WarmPool 配置、配额和工作进程循环。修复 Docker 访问后重启资源池工作进程。日志在 WarmPool 指标和 API 日志中。

### 25. MCP 服务器不可用
症状：MCP 能力发现或执行失败。检查命令路径、传输类型、端点 URL 和密钥引用。修复 MCP 运行时配置后重新测试能力。日志在工具配置页和工具运行器日志中。

### 26. 网络工具被阻止
症状：`network_request` 或远程适配器调用被策略拒绝。检查智能体网络设置、工具策略和目标允许列表。为智能体启用网络，或加入已批准目标。日志在策略日志和工具调用详情中。

### 27. Eval 数据集为空
症状：Eval 页面能打开，但没有用例运行。检查数据集用例数量和创建审计。手工添加用例，或从已完成运行创建用例。日志在 Eval 数据集详情和审计事件中。

### 28. Eval 契约意外失败
症状：回归门禁报告 grounding、安全或输出 schema 检查失败。查看契约失败载荷和运行输出。修复智能体提示词、专家契约或期望字段。日志在 Eval 运行结果和评分器 Trace 中。

### 29. 专家没有被选择
症状：应该扇出的任务仍由父智能体独自处理。检查专家触发关键词、选择器置信度和可用能力。调整专家清单或任务表述。日志在专家校准报告和选择决策中。

### 30. 市场条目签名无效
症状：安装专家市场条目时被验证阻止。检查条目签名、清单哈希、作者和已验证标记。上传修正包，或请求管理员复核。日志在市场条目详情和审计事件中。

### 31. 扇出扩展触发上限
症状：专家请求更多工作进程被拒绝。检查批次上限、请求者上限和最大扇出总数。缩小任务范围，或为组织提高配置上限。日志在扇出历史和运行事件中。

### 32. Trace 浏览器缺少 span
症状：运行存在，但看不到预期的模型或工具 span。检查 trace id 传播和可观测性导出器状态。重启导出器组件后重新运行工作流。日志在 API 追踪日志和 Trace 浏览器中。

### 33. SSE 流断开
症状：工作区事件停止更新，但运行仍在继续。检查代理缓冲、读取超时和浏览器重连行为。使用禁用流式路由缓冲的生产代理配置。日志在浏览器网络面板和代理日志中。

### 34. 成本看板很慢
症状：`/observability/cost` 在大数据量下等待或超时。检查查询缓存命中指标和数据库查询耗时。确认 Redis 可达，缓存预热后重试。日志在 Prometheus 指标和 API 日志中。

### 35. 成本看板显示为零
症状：已有模型使用，但成本总额为零。检查 model-call token 字段、供应商价格配置和所选时间窗口。修复模型调用记录，或选择正确窗口。日志在模型调用记录和成本汇总输出中。

### 36. 告警规则没有触发
症状：已知失败没有创建告警。检查规则启用状态、阈值、评估窗口和通知渠道。修复规则后重新运行告警评估。日志在告警规则历史和通知调度器日志中。

### 37. Slack 通知被拒绝
症状：Slack 渠道测试返回 HTTP 错误。检查 webhook URL 是否为 HTTPS 且仍然有效。轮换 webhook secret 后重新测试渠道。日志在通知渠道测试输出和调度器日志中。

### 38. 邮件通知未发送
症状：邮件渠道测试被接受，但收件箱没有消息。检查 SMTP host、用户名、密码、发件人和收件人。修复 SMTP 凭据，并查看供应商拒绝信息。日志在通知调度器日志中。

### 39. 前端错误报告激增
症状：设置页显示同一路由出现大量浏览器错误。检查 source map 构建、近期路由改动和失败 API 调用。修复 UI 错误或后端契约漂移。日志在 `/settings/frontend-errors` 和浏览器控制台中。

### 40. 留存 dry-run 数量不对
症状：dry-run 报告的数量与预期不同。检查策略实体类型、留存窗口、归档设置和组织 id。修正策略后重新 dry-run，再执行删除。日志在数据管理审计事件中。

### 41. 导出 ZIP 缺失
症状：数据导出完成，但无法下载归档。检查导出目录挂载、文件路径、checksum 和过期时间。修复存储权限后重新导出。日志在 API export 日志和数据管理审计事件中。

### 42. 组织删除被阻止
症状：确认删除返回校验错误。检查确认名称、角色和活动导出或留存任务。停止冲突任务，并提交完全匹配的确认文本。日志在组织删除审计记录中。

### 43. 审计日志为空
症状：设置页审计面板在操作后没有事件。检查组织范围、用户角色和事件类型过滤器。移除过滤器，或确认该动作会写审计记录。日志在 `admin_audit_events` 和 API 日志中。

### 44. 静态资源缓存头缺失
症状：浏览器反复下载带 hash 的 JS 或 CSS 文件。检查代理返回的 `/assets/*` 响应头。让资源经过静态 nginx 服务，并确认 `Cache-Control: public, max-age=31536000, immutable`。日志在代理访问日志中。

### 45. CDN 上传被拒绝
症状：资源上传脚本在 invalidation 前失败。检查 AWS 凭据、bucket 名称、region 和 CloudFront distribution id。修复环境变量，并在 clean build 后重新上传。日志在 shell 命令输出中。

### 46. k6 收到鉴权失败
症状：压测报告大量 401 或 403。检查 `HARNESS_LOAD_TOKEN` 和目标 base URL。为 staging 使用有效 engineer 或 admin token。日志在 k6 输出和 API 鉴权日志中。

### 47. k6 p99 延迟过高
症状：负载基线超过延迟目标。检查列表接口缓存指标、数据库 CPU 和慢查询。预热缓存、调优数据库索引，并与 spike 结果对比。日志在 k6 摘要、Prometheus 和数据库日志中。

### 48. 数据库连接池耗尽
症状：API 日志在负载下出现连接超时。检查 SQLAlchemy pool 设置、worker 数量和长查询。降低并发，或在数据库容量确认后提高 pool。日志在 API 日志和数据库连接指标中。

### 49. 查询缓存返回陈旧数据
症状：列表结果缺少刚创建的智能体或数据集。检查 entity version 记录和 cache key 版本。确认写路径会递增对应 entity version。日志在缓存命中/未命中指标和 `system_settings` 行中。

### 50. Redis 故障不应破坏读取
症状：Redis 已宕机，但列表接口仍应返回数据。检查 API 日志中的缓存回退，并确认数据库查询仍成功。恢复 Redis 是性能目标，但读取可用性是第一成功标准。日志在 API 日志和 readiness 详情中。

### 51. 分页 cursor 无效
症状：列表接口返回 HTTP 400，并显示 `Invalid pagination cursor`。检查客户端是否原样传递上一页响应返回的 cursor。把分页重置到第一页后重试。日志在浏览器网络面板和 API 请求日志中。
