# 常见问题

## 这是聊天机器人吗？

不是。产品表面是智能体 Harness。聊天只是输入方式之一，平台会围绕每条运行记录计划、工具、沙箱、子智能体、Eval、Trace、记忆、知识库和策略证据。企业验收应检查这些证据，而不是只看最后一句回复。

## 每个任务都需要 RAG 吗？

不需要。依赖私有文档的证据绑定回答需要本地知识库或连接器。一般运维任务可以不使用 RAG，但没有证据支持的事实性结论应视为质量风险。Eval 契约可以要求引用或证据不足处理。

## 最安全的首个生产工作流是什么？

使用只读智能体，绑定范围很窄的知识源，不开放写入工具，配置严格证据绑定契约，并从成功试运行保存 Eval 数据集。发布后用成本看板、Trace 和运行详情复核每次变更。

## 子智能体什么时候应该被调用？

当任务需要独立专业判断、并行证据收集或团队模式分工时，应显式调用子智能体或专家模板。调用结果必须出现在父运行、运行详情或团队任务证据中，不能只在文本里声称已经调用。
