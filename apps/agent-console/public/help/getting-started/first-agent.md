# 运行第一个智能体任务

从看板或智能体列表进入工作区，输入一个具体目标，选择模型预置后提交。Harness 会创建运行，保存请求，让规划器生成计划，并记录后续所有事件。运行详情会展示计划 DAG、模型调用、工具调用、子智能体、回放、Eval 保存动作、上下文清单和 Trace 证据。

一条合格的首次运行应该让另一位操作员无需读取服务端日志也能复核结果。检查点包括：任务目标是否明确，计划是否拆出可执行步骤，工具是否只在授权范围内运行，模型调用是否有 token 与成本记录，失败或重试是否出现在事件流中。

如果任务需要企业知识，先给智能体绑定知识源并确认检索命中；如果任务需要工具，先确认智能体拥有对应能力附件，并且高风险工具已经配置审批策略。完成后把成功运行保存为 Eval 用例，作为后续发布回归基线。
