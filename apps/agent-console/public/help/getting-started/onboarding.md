# 初始化检查清单

初始化流程用于准备第一条可用运行所需的最小环境。先配置模型供应商，确认 API 连通性；如果部署环境为空，可以加载演示数据；随后从工作区运行第一个任务。向导会记录设置状态，帮助运维人员区分“还没配置完成”和“运行时失败”。

演示数据会创建代表性的智能体、知识源、Eval 数据集、可观测性记录和历史运行行，但不会要求生产凭据。完成检查清单后，看板会成为默认入口，页面引导会提示主要工作面：智能体工作室、工具注册表、知识库、Eval、子智能体、成本看板和管理设置。

模型密钥应放在服务端配置或连接器密钥中。不要把长期有效的供应商密钥写进提示词、知识文档、Issue 评论或截图。交付验收时应确认默认模型可用、演示数据可重置、健康检查返回 ready，并且每个左侧导航页面能打开。
