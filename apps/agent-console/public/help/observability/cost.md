# 成本看板

成本看板把模型、专家和适配器的成本证据按时间窗口和分组聚合。模型价格行负责把 token 转换为 USD；工具调用输出可以携带适配器成本；当子智能体单独记录预算时，专家预算证据可以补齐父运行的成本视图。

内置官方模型价格必须来自有来源的行，包含 URL、抓取时间、单位、币种、有效期、来源哈希和验证状态。缺失、过期、SKU 模糊、未验证或需要汇率换算的价格，会作为阻塞证据继续显示，而不是静默按零成本汇总。

调提示词和上下文策略时应查看成本视图。输入 token 过高通常来自 RAG 证据过大、摘要过期、近期轮次太多或专家扇出太宽；适配器成本过高通常说明写入调用重复、缺少幂等键或请求了不必要的供应商接口。
