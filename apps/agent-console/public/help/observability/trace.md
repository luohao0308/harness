# Trace 追踪浏览器

Trace 浏览器把运行活动和本地 OpenTelemetry span 连接起来。一条 Trace 可以展示 API 请求、模型调用、工具执行、沙箱动作、Eval 评分和可观测性导出器。运行详情面向操作员证据，Trace 浏览器帮助工程师检查耗时和服务边界。

当日志、指标和事件都携带同一个 trace id 时，排障效率最高。遇到延迟、流式输出中断或工具执行顺序不清时，从运行 id 开始，按服务查看 span，再与事件流顺序对照。

事件解释产品状态，例如任务何时进入 running、何时等待审批、何时失败；span 解释时间花在哪里，例如模型网关等待、沙箱冷启动、数据库查询或外部适配器响应。两者结合才适合做发布级故障复盘。
