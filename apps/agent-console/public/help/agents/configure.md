# 配置智能体行为

智能体配置要回答三个问题：哪个模型处理任务，哪些上下文允许进入提示词，哪些工具可以执行。系统提示词设置行为边界；token 预算决定近期消息、置顶上下文、长期记忆、压缩摘要、RAG 证据和网页研究如何竞争空间。

配置改动应当按发布变更处理。提示词的一行调整，可能同时影响工具调用、专家路由、Eval 通过率、成本和证据质量。推荐流程是先编辑配置，再运行一个小型工作区任务，检查运行详情，最后执行对应 Eval 数据集。

复核上下文清单是排查回复不完整或成本过高的关键动作。清单会显示包含和省略的引用、裁剪原因、提示词哈希与策略决策。不要把安全策略藏在知识文档里，策略应放在智能体配置、工具策略或 Eval 契约中。
