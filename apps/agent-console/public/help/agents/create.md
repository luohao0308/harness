# 创建智能体

智能体由模型路由、系统提示词、能力附件、知识范围、Sandbox 默认值和上下文策略组成。使用智能体工作室为一个清晰的工作族创建命名智能体，例如研究、代码审查、运维处置或客服分流。角色描述要短、可测试，并且能解释这个智能体应该拒绝什么。

只给智能体挂载它确实需要的工具，因为工具可见性会进入运行清单，并成为后续 Eval 和审计证据。知识源也应保持边界清晰：私有流程用智能体级知识，跨多个智能体复用的规范才放到组织级知识库。

已有流程优先使用模板。只有当提示词、工具权限、RAG 来源、预算策略或审批要求不同，才创建新的智能体。创建后运行一个小任务，检查运行详情证据，再保存为 Eval 用例，作为这个智能体的最小交付验收。
