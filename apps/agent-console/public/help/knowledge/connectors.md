# 知识连接器

知识连接器把 Harness 检索接到外部知识系统，例如 Dify、Coze 兼容端点或自定义检索服务。连接器 API Key 存为服务端密钥，不会返回浏览器。默认先运行本地知识检索；本地证据不足时，已配置连接器可以返回带来源的命中。

连接器命中会成为引用和提示词清单条目，所以它们必须保持来源绑定。预览状态的连接器可以保存配置，但不应被算作完整可用的证据绑定能力。失败调用应返回策略或健康状态提示，而不是让智能体继续给出无证据结论。

连接器适合已有访问控制的企业知识库。数据集范围要窄，并验证返回片段确实包含智能体完成任务所需证据。上线前至少测试一次正常命中、空结果、鉴权失败和超时路径。
