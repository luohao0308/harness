# 证据绑定与引用

证据绑定表示智能体回答必须连接到可检查的证据。Harness 会记录检索会话、检索命中、引用记录、提示词清单、策略审计行和模型调用绑定元数据。运行详情会展示本地状态、引用键、网页来源、向量回退状态、省略证据和清单哈希。

Eval 可以据此检查必需引用、禁用证据泄漏、无依据标记、证据不足行为，以及 fixture 与已验证供应商状态。受监管流程中，正确答案但缺少引用仍然不完整；引用来自被拒绝或过期证据则更危险，因为它会制造错误信心。

排障时优先看引用。确认每个关键结论是否有命中片段，命中片段是否来自允许范围，提示词清单是否包含实际传入模型的上下文。证据必须保持来源绑定，不能只把结论复制到提示词中伪装成检索结果。
